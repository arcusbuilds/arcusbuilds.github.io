Merged pull requests

A plain-language record of the problems I worked on and the changes that were merged.

triton-lang/triton · PR #11720

Avoid per-case streams in the fused-softmax benchmark

Problem: Creating a new device stream for every benchmark case caused reserved memory to grow throughout the sweep.

Fix: Removed the per-case stream calls so the benchmark uses the current stream and can complete the full 294-case sweep.

podman-container-tools/podman · PR #29795

Preserve restart policy during compatibility updates

Problem: Compatibility updates reset a container's restart policy when the request did not provide a replacement.

Fix: Preserved the existing policy unless a new value is explicitly supplied and added regression coverage.

tinygrad/tinygrad · PR #18229

Fix einsum when a repeated index is not last

Problem: Diagonal extraction moved tensor axes without moving their labels, producing transposed results, wrong sums, or errors.

Fix: Moved the repeated label with its axis and added cases covering the broken expressions.

3dem/relion · PR #1369

Reuse exact-size blocks in the GPU allocator

Problem: The CUDA and HIP allocators skipped a free block when its size exactly matched the request, causing fragmentation or an out-of-memory failure.

Fix: Allowed exact matches in both free-list implementations so those blocks are reused.

NVlabs/cutile-rs · PR #282

Expose kernel-cache eviction without autotuning

Problem: Serving engines could not evict compiled kernels unless they enabled the experimental autotuning feature.

Fix: Made the existing eviction APIs available in default builds while keeping autotuning feature-gated.

KhronosGroup/SPIRV-Cross · PR #2679

Restore strict C++11 lambda compatibility

Problem: A C++14 default lambda argument broke strict C++11 builds.

Fix: Removed the default argument and passed the value explicitly at each call site without changing shader output.

google/highway · PR #3328

Guard SVE2 bf16 support correctly

Problem: The SVE2_128 path could advertise bf16 support even when the compiler lacked the scalar bf16 type.

Fix: Applied the scalar-type guard to every relevant target path and added a compile-time sanity check.

intel/llvm · PR #23056

Use pkg-config include paths for Level Zero

Problem: Custom-prefix Level Zero installs failed or mixed header versions because CMake ignored include paths reported by pkg-config.

Fix: Forwarded the additional pkg-config include directories without changing the single-path variable used elsewhere.

open-telemetry/opentelemetry-collector-contrib · PR #50602

Validate Prometheus exemplar IDs

Problem: The Prometheus receiver padded, truncated, or dropped malformed trace and span IDs.

Fix: Converted only valid non-zero IDs and retained invalid values as filtered attributes.

kubernetes-sigs/dra-driver-nvidia-gpu · PR #1400

Add coverage for GPU partition mapping

Problem: The code mapping GPU and MIG state into Kubernetes partitionable devices had no unit tests.

Fix: Added tests for all partition helpers, capacity fallbacks, counter agreement, mapping, and unsupported types.

open-telemetry/opentelemetry-collector-contrib · PR #50576

Preserve malformed remote-write exemplar IDs

Problem: The Prometheus remote-write receiver silently changed or discarded invalid trace and span ID labels.

Fix: Converted valid IDs and kept malformed or all-zero values as filtered attributes with regression tests.

vllm-project/vllm · PR #54007

Unblock FlashMLA builds with MSVC

Problem: FlashMLA targets used M_LOG2E, which MSVC does not expose unless a compile definition is set before including cmath.

Fix: Added _USE_MATH_DEFINES to both affected targets only when compiling with MSVC.

open-telemetry/opamp-go · PR #641

Advertise example-server capabilities

Problem: The example server never told agents which remote configuration and connection features it supported.

Fix: Set the implemented capability bitmask on every response produced by the connection's message handler.

bytecodealliance/wasmtime · PR #14215

Apply configured fuel costs to constant expressions

Problem: Constant-expression operators and synthesized start calls always consumed one unit of fuel, ignoring configured operator costs.

Fix: Routed those operations through the configured cost model and added regression tests.

rust-lang/rust-clippy · PR #17632

Fix case-mismatched lint lookup in --explain

Problem: Beta and nightly Clippy lowercased the requested lint but compared it with uppercase lint names, so every lookup failed.

Fix: Restored the case normalization used by the lookup and added command-level coverage.

systemd/systemd · PR #43521

Stop lid-open events from enabling airplane mode

Problem: An HP ENVY x360 emitted a keyboard scan code on lid open that desktops interpreted as the wireless toggle.

Fix: Added the model to the existing hardware quirk that suppresses the false key event.

near/nearcore · PR #16267

Report missing accounts accurately in access-key RPCs

Problem: Access-key queries could not distinguish a missing account from a missing key or an empty key list.

Fix: Checked account existence on miss paths and returned the appropriate account-missing response for each endpoint while preserving the legacy query shape.

grafana/pyroscope · PR #5538

Document the retention-period setting

Fix: Removed the tag and regenerated the reference and example configuration.

zarr-developers/zarr-python · PR #4277

Name packages that provide missing codecs

Problem: Unknown-codec errors repeated the codec name but did not tell users which installable package provided it.

Fix: Added provider mappings so errors can suggest the package that supplies a known codec.

PCRE2Project/pcre2 · PR #953

Fix: Reworded the lead-in using the language agreed on in the tracking issue.

uutils/coreutils · PR #14005

Give sort read errors useful context

Problem: sort printed only the raw operating-system error when reading input failed.

Fix: Added read-failure context and removed the noisy numeric errno using an existing helper.

tile-ai/tilelang · PR #2924

Preserve memory ordering in vectorized atomics

Problem: Vectorization dropped atomic_add's memory_order operand, silently falling back to relaxed ordering and exposing invalid PTX paths.

Fix: Carried trailing operands through vectorization and corrected the fp16 and bf16 ordered-atomic implementations.

DataDog/fastjq · PR #38

Propagate RunFunc callback errors

Problem: RunFunc treated callback failures like ignorable evaluation errors, preventing callers from stopping iteration.

Fix: Wrapped callback failures as control-flow errors internally and returned the caller's original error unchanged.

NVIDIA/cccl · PR #10699

Fix: Added printers for static and dynamic extents, including nested, const, zero-length, and mutated spans.
